# Портфель

Мій рахунок в Interactive Brokers як застосунок: скільки є, скільки заробив, як іде проти ринку,
що лежить у портфелі й на що звернути увагу. Щодня записує вартість кожного активу на закритті біржі,
тож можна порівняти будь-які дві дати й побачити, як ріс портфель. Ставиться на телефон і комп'ютер,
працює без інтернету з останніми збереженими даними, має світлу й темну тему.

Адреса: https://mykytatitar-rgb.github.io/invest/

## Як це влаштовано

```
IBKR (звіт Flex) ──► GitHub Actions щоранку ──► зашифрований data.enc.json у гілці invest-data ──► застосунок
                      + ціни VOO (Yahoo)                                                          розшифровує
                      + курс НБУ                                                                  твоїм паролем
```

- Кожен запуск додає запис про останнє закриття біржі: вартість рахунку, кожного активу й вільних грошей.
  Записи накопичуються, тож історія не обрізається на році. Якщо оновлення кілька днів не працювало,
  пропущені закриття відновлюються: кількість паперів рахується за угодами, ціни беруться з Yahoo
  й прив'язуються до цін IBKR.
- Сайти GitHub Pages публічні, тому дані лежать лише в зашифрованому вигляді (AES-GCM, ключ з пароля
  через PBKDF2-SHA256, 600 000 ітерацій). Без пароля файл не прочитати.
- Пароль ніде не зберігається у відкритому вигляді: він є лише в секреті GitHub і в твоїй голові.
  На пристрої, якщо поставити галочку «Пам'ятати», лежить похідний ключ.
- Токен IBKR лежить тільки в секретах GitHub. У браузер він не потрапляє.
- Застосунок нічого не купує й не продає: лише читає звіт.

## Налаштування, один раз (близько 10 хвилин)

### 1. Звіт Flex в IBKR

1. Зайди в Client Portal IBKR: **Performance & Reports → Flex Queries**
   (або **Menu → Reporting → Flex Queries**).
2. У блоці **Activity Flex Query** натисни **+**. Назва: `Portfel`.
3. У **Sections** відкрий по черзі ці розділи, у кожному натисни **Select All** і **Save**:
   - **Net Asset Value (NAV) in Base**: вартість рахунку по днях;
   - **Open Positions**: у параметрах обери **Summary**;
   - **Trades**: у параметрах обери **Execution**;
   - **Cash Transactions**: залиш усі типи (поповнення, дивіденди, податки) і рівень **Detail**;
   - **Cash Report** (не обов'язково, але корисно).
4. **Delivery Configuration**: Format **XML**, Period **Last 365 Calendar Days**.
5. **General Configuration**: Date Format **yyyyMMdd**, Time Format **HHmmss**,
   Date/Time Separator **; (semi-colon)**. Решту залиш як є.
6. **Continue → Create**. У списку звітів біля `Portfel` натисни значок інформації:
   там буде **Query ID** (число). Збережи його.

### 2. Токен Flex Web Service

1. На тій самій сторінці **Flex Queries** праворуч відкрий **Flex Web Service Configuration**.
2. Увімкни **Flex Web Service Status** і натисни **Save**. З'явиться **Current Token**.
3. Якщо створюєш новий токен: строк дії обери найдовший (до року),
   **обмеження за IP не став**, бо адреси GitHub щоразу інші.

### 3. Секрети в GitHub

Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**, три секрети:

| Назва | Що вписати |
|---|---|
| `IBKR_FLEX_TOKEN` | токен з кроку 2 |
| `IBKR_FLEX_QUERY_ID` | Query ID з кроку 1 |
| `INVEST_PASSWORD` | пароль до застосунку, від 8 символів |

Пароль можна лишити той, яким відкривається знімок зараз, або придумати свій.
Якщо зміниш, застосунок після першого оновлення один раз попросить новий пароль.

### 4. Перший запуск

**Actions → Портфель, оновити дані → Run workflow.** За хвилину-дві з'явиться зелена галочка.
Відкрий застосунок і натисни кнопку оновлення праворуч угорі.

Далі все працює саме: вівторок–субота, двічі зранку (за київським часом близько 7:17 і 12:47),
бо звіт IBKR за торговий день з'являється вночі.

## Як поставити застосунок

- **iPhone, Safari**: «Поділитися» → «На початковий екран».
- **Android, Chrome**: меню ⋮ → «Встановити застосунок» або «Додати на головний екран».
- **Комп'ютер, Chrome чи Edge**: кнопка «Встановити» в застосунку або значок у рядку адреси.

## Якщо щось не так

- **Замість «Портфеля» відкрились «Справи».** Онови сторінку ще раз. Таке буває лише перший раз
  на пристрої, де вже стоять «Справи»: їхній старий service worker перехопив адресу, а при
  першому ж відкритті оновився.
- **Червоний хрестик в Actions.** Відкрий запуск і крок «Звіт IBKR і шифрування»: там написано
  українською, що не так (прострочений токен, неправильний Query ID тощо).
- **Застосунок пише, що дані застаріли.** Перевір вкладку Actions. Токен Flex діє до року:
  коли спливе, створи новий і онови секрет `IBKR_FLEX_TOKEN`.
- **Щоденний запуск зник.** GitHub вимикає розклад у публічних репозиторіях після 60 днів без
  змін. Відкрий Actions і натисни **Enable workflow**.

## Файли

| Файл | Що робить |
|---|---|
| `index.html`, `app.css`, `app.js`, `boot.js` | сам застосунок, без збирання й залежностей |
| `sw.js` | робота без інтернету (лише в межах `/invest/`) |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | встановлення як застосунок |
| `fonts/` | шрифт Geologica (SIL Open Font License, див. `fonts/OFL.txt`) |
| `tools/update_data.py` | оновлення даних: Flex → шифрування |
| `../.github/workflows/invest-data.yml` | щоденний запуск оновлення |

Перевірити оновлення на своєму комп'ютері зі збереженим XML-звітом, без мережі:

```
pip install cryptography
INVEST_PASSWORD=... python tools/update_data.py --xml statement.xml --offline --out data.enc.json
```
