# Справи

Особистий список задач: списки-колонки, дати, повтори, підзавдання, зірочки,
перетягування, на телефоні — вкладки. Ставиться як застосунок на телефон і
комп'ютер і працює без інтернету.

Адреса: https://mykytatitar-rgb.github.io/

## Як влаштовано

- Статичний сайт без збирання: `index.html`, `tasks.css`, `tasks.js`, `sw.js`.
  GitHub Pages публікує гілку `main` сам, приблизно за хвилину після push.
- Дані — у базі Supabase (адреса й публічний ключ у `config.js`), таблиця
  `records`, види `todo_task` і `todo_list`, кожне завдання окремим рядком.
  Вхід поштою й паролем, один раз на пристрої.
- `sw.js`: сторінка й код беруться з мережі з перевіркою, кеш — запасний
  варіант, тож номери версій піднімати не треба.
- Іконки: `node make-icons.js` (числа ті самі, що в `icon.svg`).
- Перенесення списку ззовні — посиланням `#import=z.<дані>`: дані після «#»
  на сервер не йдуть.
